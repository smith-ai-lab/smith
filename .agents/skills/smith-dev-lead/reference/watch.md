# The lead's watcher

One bash loop, run with `run_in_background` and the longest timeout. It ends only when something needs the lead, and its end wakes the lead. **Start it again after every wake, including when the 2-hour limit stops it:** on 2026-11-01 it lapsed at 23:15 and runners idled all night unseen. `SEEN` remembers what it already reported, so each problem wakes the lead once. **The lead is woken only when needed** (owner, 2026-11-02: "if you are getting woken for no reason, something that can be deterministically solved, then we should change that. You should be woken when you are needed. Or when I talk to you"): half the lead's overnight turns on 2026-11-02 (about 80, about $29) were wakes a script could have settled. What it does on its own goes to `watch-actions.log` beside `SEEN`; read it at each wake.

```bash
R=smith-ai-lab/smith
FOOT=$'\n\n---\n_Generated by [Claude Code](https://claude.ai/code)_'
issues() { gh api "repos/$R/issues?state=open&per_page=100&labels=$1" --jq "$2" 2>/dev/null; }
START=$(date -u +%Y-%m-%dT%H:%M:%SZ)
# @lead: comments on #1406 since the watcher started (`since` keeps working past 100 comments)
lead() { gh api "repos/$R/issues/1406/comments?per_page=100&since=$START" --jq '[.[]|select(.body|startswith("@lead:"))]|length' 2>/dev/null; }
SEEN=${SEEN:-$HOME/.lead-seen}; touch "$SEEN"
LOG=${LOG:-$(dirname "$SEEN")/watch-actions.log}
seen() { grep -qx "$1" "$SEEN" && return 1; echo "$1" >> "$SEEN"; }
did() { echo "$(date -u +%FT%TZ) $*" >> "$LOG"; }
say() { gh api "repos/$R/issues/$1/comments" -f body="$2$FOOT" >/dev/null 2>&1; }

# What a script can settle, it settles; only what needs judgment wakes the lead (owner, 2026-11-02:
# "You should be woken when you are needed. Or when I talk to you").
fix() {
  # every ticket a blocked one waits for is closed: unblock it
  for i in $(issues blocked '.[]|select(.pull_request==null)|.number'); do
    w=$( { gh api "repos/$R/issues/$i" --jq .body; gh api "repos/$R/issues/$i/comments?per_page=100" --jq '.[].body'; } 2>/dev/null | grep -oiE 'waits for[^.]*' | grep -oE '#[0-9]+' | tr -d '#' | sort -u)
    [ -z "$w" ] && continue
    open=0; for d in $w; do [ "$(gh api repos/$R/issues/$d --jq .state 2>/dev/null)" = closed ] || open=1; done
    [ $open = 0 ] && gh api -X DELETE "repos/$R/issues/$i/labels/blocked" >/dev/null 2>&1 &&
      say "$i" "Unblocked (lead's watcher): every ticket this waits for is closed ($(echo $w | sed 's/[0-9]*/#&/g'))." && did "unblocked #$i"
  done
  # a green PR that is not queued: merge main in and turn auto-merge on
  for p in $(gh api "repos/$R/pulls?state=open&per_page=50" --jq '.[]|select(.auto_merge==null and .draft==false and (.updated_at|fromdateiso8601<now-1800))|.number' 2>/dev/null); do
    [ "$(gh api repos/$R/pulls/$p --jq .mergeable_state 2>/dev/null)" = clean ] || continue
    gh api -X PUT "repos/$R/pulls/$p/update-branch" >/dev/null 2>&1
    gh api -X PUT "repos/$R/pulls/$p/ccr/auto_merge" >/dev/null 2>&1 && did "re-armed PR #$p" || { seen "arm$p-$(date +%H)" && echo "PR #$p is green but auto-merge would not turn on"; }
  done
  # a PR red or conflicted and untouched for an hour: release its ticket to the next runner
  for p in $(gh api "repos/$R/pulls?state=open&per_page=50" --jq '.[]|select(.draft==false and .head.ref!="claude/vibrant-mendel-tvpj1l" and (.updated_at|fromdateiso8601<now-3600))|.number' 2>/dev/null); do
    sha=$(gh api repos/$R/pulls/$p --jq .head.sha 2>/dev/null)
    why=
    [ "$(gh api repos/$R/commits/$sha/check-runs --jq '[.check_runs[]|select(.name=="ci")|.conclusion]|first' 2>/dev/null)" = failure ] && why="its ci is red"
    [ "$(gh api repos/$R/pulls/$p --jq .mergeable 2>/dev/null)" = false ] && why="it has a merge conflict with main"
    [ -z "$why" ] && continue
    seen "rel$p-$sha" || continue
    t=$(gh api repos/$R/pulls/$p --jq '.title + " " + (.body // "")' 2>/dev/null | grep -oiE '(closes|fixes|resolves) #[0-9]+|\(#[0-9]+' | grep -oE '[0-9]+' | head -1)
    [ -z "$t" ] && { echo "PR #$p: $why, untouched for an hour, and no ticket found to release"; continue; }
    gh api -X DELETE "repos/$R/issues/$t/labels/claimed" >/dev/null 2>&1
    say "$t" "Claim released (lead's watcher): PR #$p has gone an hour with no push and $why. The next runner takes that PR over: check out its branch, merge main in, make ci green, and push. Do not open a second PR." && did "released #$t (PR #$p: $why)"
  done
}

# Only what needs the lead.
check() {
  top=$(gh api repos/$R/issues/73 --jq '.body|split("\n")[0]' 2>/dev/null)
  n=$(echo "$top" | sed -n 's/.*N=\([0-9]*\).*/\1/p')
  if [[ $top == *"pool: running"* ]]; then
    ready=$(issues task '[.[]|select(.pull_request==null and ([.labels[].name]|(index("claimed") or index("blocked"))|not))]|length')
    [ -n "$ready" ] && [ "$ready" -lt "${n:-0}" ] && seen "ready$ready-$(date +%F)" && echo "only $ready ready tickets for N=$n: write or split tickets"
  fi
  run=$(gh api "repos/$R/actions/workflows/ci.yml/runs?branch=main&status=completed&per_page=1" --jq '.workflow_runs[0]|"\(.conclusion) \(.head_sha)"' 2>/dev/null)
  [ "${run%% *}" = failure ] && seen "red${run##* }" && echo "main's ci is red at ${run##* }"
  for i in $(issues blocked '.[]|select(.pull_request==null)|.number'); do
    w=$( { gh api "repos/$R/issues/$i" --jq .body; gh api "repos/$R/issues/$i/comments?per_page=100" --jq '.[].body'; } 2>/dev/null | grep -oiE 'waits for #[0-9]+')
    [ -z "$w" ] && seen "w$i" && echo "#$i is blocked with no Waits-for line (a runner's question?): answer it, name what unlocks it, or remove blocked"
  done
  main=$(gh api "repos/$R/commits/main" --jq '"\(.sha) \((now-(.commit.committer.date|fromdateiso8601))>3600)"' 2>/dev/null)
  [ "${main##* }" = true ] && [ "$(gh api "repos/$R/pulls?state=open&per_page=1" --jq length 2>/dev/null)" -gt 0 ] &&
    seen "stall${main%% *}" && echo "no merge into main for an hour with PRs open"
}

base=$(lead); t=0
while :; do
  m=$(lead); [ -n "$m" ] && [ "$m" -gt "${base:-0}" ] && { echo "new @lead: on #1406"; gh api "repos/$R/issues/1406/comments?per_page=100&since=$START" --jq '[.[]|select(.body|startswith("@lead:"))][-1].body' | head -40; exit 0; }
  if [ $((t % 10)) = 0 ]; then why=$(fix); [ -n "$why" ] && { echo "$why"; exit 0; }; fi
  if [ $((t % 60)) = 0 ]; then why=$(check); [ -n "$why" ] && { echo "$why"; exit 0; }; fi
  t=$((t+1)); sleep 60
done
```
- **Done without the lead (every ten minutes):**
  - Everything a blocked ticket waits for is closed: it removes `blocked` and says so on the ticket.
  - A green PR not in the merge queue (GitHub ignores auto-merge on a PR that is already green; the queue drops a PR whose queue run fails): it merges main in and turns auto-merge on through `PUT pulls/N/ccr/auto_merge` (#1522 sat green for 90 minutes).
  - A PR red or conflicted and untouched for an hour: its runner has ended. It removes `claimed` from the ticket the PR names and comments `Claim released (lead's watcher)`, so the next runner takes that PR over (smith-dev-runner step 1; #1562 sat conflicted for four hours).
- **Wakes the lead (every hour, once per problem):** fewer ready tickets than N (write or split tickets); main's ci red; a blocked ticket with no Waits-for line (likely a runner's question; owner, 2026-11-02, "we should never let you mark something as blocked unless you have a ticket saying what unlocks it"); no merge into main for an hour with PRs open; a PR it could not re-arm or release.
- **The mailbox** is read with `since=<start>`, so it keeps working past 100 comments on #1406.
- **The merge queue has no REST listing:** "stalled" means no new commit on main for an hour while pull requests are open.
