smith check: run all the project's checks

usage: smith check [-v] [--changed [--base <ref>]] [--require <parts>] [-D<name>=<value>...]

flags:
  -v                  show every part's output and every task's time
  --changed           lint and test only what the change since main reaches (--base <ref> names another base)
  --require <parts>   fail when a part did not run on this host: fmt, docs, lint, test, prove, macos-lint, macos-tests, or all
  -D<name>=<value>    an option the project's build.c reads

examples:
  smith check
  smith check --changed
  smith check --require all
