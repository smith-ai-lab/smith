smith check: run all the project's checks

usage: smith check [-v] [--changed [--base <ref>]] [--require <parts>|all] [-D<name>=<value>...]
       smith check --plan [--base <ref>]

flags:
  -v                  show every part's output and every task's time
  --changed           lint and test only what the change reaches; --base <ref> is what it is compared with
  --plan              print what the change touches (scope=none|docs|full, docs_tests, changed) and run nothing
  --require <parts>   fail when a part is not run here: fmt, docs, prove, lint, test, macos-lint, macos-tests, or all
  -D<name>=<value>    an option the project's build.c reads

examples:
  smith check
  smith check -v
  smith check --changed --require all
  smith check --plan --base origin/main
