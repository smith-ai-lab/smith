# Smith knowledge

This folder says what Smith is. How to work on it is in [../.agents/skills/](../.agents/skills/).

- [language/](language/index.md): every feature of the language, one file each, read in order as a tour. Anything not in it is not in Smith.
- [library/](library/index.md): the standard library's modules, one file each, including the operations of each effect a module declares.
- [idioms.md](idioms.md): which form of the language to reach for, for state, loops, numbers, failure, and names, with the shape from another language each replaces.
- [grammar.md](grammar.md): lexical rules, operator precedence, the EBNF grammar, and the properties the parser relies on.
- [compiler.md](compiler.md): how the compiler is designed, from how `for` is compiled and how a whole number is kept to backends, testing, timings, and bootstrap.
- [okf.md](okf.md): the format this folder follows, and the conventions we add to it.
