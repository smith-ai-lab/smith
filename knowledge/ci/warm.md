# Testing a main-only step before it merges

**Testing a main-only step before it merges** (#2769). `warm` writes (the caches, the `step-cache` release, the body of #2751) and a push to `main` is the only place that ran it, so a broken step was found after merge (#2752's timing step, fixed in #2761 after about 90 minutes). Now `changes` compares the job with the base's (`yq '.jobs.warm'` of both `ci.yml`, plus a diff of `.github/actions/setup-smith`) and outputs `warm`/`warm_os`: a pull request that changes either runs `warm` as a **dry run** on Linux only (a push to `main` still runs both OSes for real; a pull request that leaves `warm` alone does not run it, and a queue entry never runs the dry run). The job sets `DRY_RUN=1` for any event but a push; each write step is skipped on it (`Save the step cache`, `Save the lint and proof caches`) or ends early after printing what it would have written to the step summary (the release upload lists the assets and their sizes, the timing step prints the whole body of #2751). So a new write step goes behind `DRY_RUN` and prints its payload. The job keeps its `contents`, `actions` and `issues` permissions (a job's `permissions` cannot depend on the event; a fork's pull request gets a read-only token anyway), and the dry run writes nothing with them. It is not a required check: read its summary. It costs one Linux `warm` (about the same as a push's, dominated by the cold timing build) on a pull request that touches the job.

**One warm per OS at a time** (#3069). `warm` took 22.9 hosted runner-minutes a push to `main` (Linux 14.2, macOS 8.7, 16 pushes on 2026-11-10), about 11 % of all hosted minutes ([ledger](ledger.md)). Its job has `concurrency: warm-main-<os>` with `cancel-in-progress: false`: a running warm finishes, and a warm still waiting for the one before is replaced by the warm of a newer push. Nothing is lost: the older commit's cache would be keyed by its own stage0, and every job after the newer push fetches the newer one. The replaced push run ends `cancelled`; no required check reads a push run. A pull request's dry run has a group of its own run. The Actions artifact `smith-steps-linux-<sha>` went in the same change: no job or session read it (sessions read the `step-cache-<sha7>` release assets, #2772), and its upload took 3.35 minutes a push.
