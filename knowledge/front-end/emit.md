# front::emit (`front/emit*.smith`, #1119)

`emit::module(context, &m, options)` turns a `front::ast` module into a verified LLVM module through LLVM's C API, or an `Error` with a span. The protocol is the top comment of `front/emit.smith`.
- Rules: no recursion (a work stack and a value stack); a handler pops operands and pushes one value; a node that needs a child first pushes a `then` continuation; pass 1 declares, pass 2 emits bodies; allocas go in the entry block.
- `Target` and `Options` pick the triple and layout. Symbols are the module path joined with `::`; exported (or `pub`) is external, the rest internal.
- Handlers dispatch with `if` chains, never `case .name:` ([body-files](../body-files.md)); read payload fields into locals before any call.
- No arena around LLVM: LLVM allocates with `malloc`, which smith routes to the allocator in force, so a test must not hold an arena while it emits or runs the JIT.
- Tests run the result in LLJIT (`emit_jit.smith`) and compare golden IR (`tests/front/emit/`).

**Files**: `emit.smith` (passes, the walk, routing), `emit_state.smith` (shared types, `Emitter`, hooks; its own file to break an import cycle), then one file per area, no two tickets sharing one.
- Anonymous structs and unions (#2984, `front/emit_record.smith`): a payload variant's `struct { ... }`, a field of type `struct { ... }` or `union { ... }`, are emitted as an LLVM struct of the fields in order (a union is one array as big and as aligned as its biggest member, every member at offset 0, sized by the target's data layout) and registered in `Emitter.records` under a key spelled from the fields (`struct { a: i32; b: i64; }`), which is also the LLVM name. Identity is structural: two places with the same fields share one LLVM type, while the checker keeps them apart (nominal per place), which no accepted program can observe. The walk is an explicit stack, at most 8 deep and 64 fields; deeper, or a bit-field, is `not emitted yet: an anonymous ... nested more than 8 deep` (and the like). A type alias's written type is read in its own module's scope (`emit::type_of_alias`), and a bare name that the import scope sends back to itself is an `unknown type` (`Emitter.scoped_leaf`), which was the stack overflow behind the count's 19 `compile ended with status <n> (signal)` rows. Not reached yet: a generic anonymous payload (`Maybe(i64)` is `not yet typed: the applied type` in the checker) and `fields(T)` of one; a C header's anonymous member is a named record (`smith_anonymous_N`, `shim/cimport.cpp`). Test: `tests/front_emit_record_test.smith`.
- A capitalized path used as a value (`High`, `area.Square`, `c.EOF`) is parsed as a type; when it names no type the checker checks it as a name and records that name as the node's twin (`type_value_name` in `front/types_expr.smith`, #2984), so an enumerator or a C constant is emitted as one and anything else is the name's own error (`write .High`). `_Generic` is an error: it is not in smith's language. `x == .ok` and `r != .error` over a Result compare its tag (`emit_control::option_operand`).
- Slices `[]T` and `str` are `{ data, count }` (#1623): a string literal is a constant `str`, `s[i]` checks the index against the count in every build, `s[a:b]` and `countof(s)` read the pair, and `for x in s` walks it.
- Multi-dimensional arrays (#1710): `[5,3]T` is `[5][3]T`, `[,3]T` a slice of `[3]T`, and `[,]T`/`[,,]T` (up to 8) a block `{ ptr, [N x usize] }`, one count per run-time dimension, row-major, strides derived. `x[i, j]` is `x[i][j]`; a row of a block is a block of one dimension fewer (a slice for the last two) sharing the elements, checked per dimension; a fixed `[N][M]T` converts to a block; `countof(x)` is the first count.
- `emit_vector` (`vec(T, N)`), `emit_arith` (integer expressions), `emit_control`, `emit_call`, `emit_memory`, `emit_debug`, `emit_option`, `emit_iter`, `emit_match`, `emit_value`, `emit_tuple`, `emit_lambda`, `emit_jit` (test helper).
- Three hooks in `Emitter`, set by `emit::module`, let a handler reach `emit.smith` without importing it: `state::type_of` (a type expression), `state::type_of_node` (the checker's type of a node) and `state::convert`.
- `state::convert(e, value, to, span, site)` pushes `value` as a `to`: as is, widened by the checker's rules, or wrapped for an option; else the site's error (`initializing X with Y`).
- `type_of_node` with no `Options.checked` is an Error, "this needs the checker's types".

- Routing in `emit.smith`: `type_of` sends `?T`, a tuple and a `fn` type to their file and a one-segment name to `match::type_enum` before records.
- A `variant` goes to `emit_option` when the hint or the checker's type is an option, else to `emit_match`; a `stmt_expr` goes to `match::value_of` for a `match`, else `emit_value`.
- A member named by a digit is a tuple member; `declare_all` sends an `enum` to `enum_decl`; a function's last line that is a `match`, block or `if`/`else` with values is returned as `value_of`.
- The state of the table comes from the files; a later docs pass updates it. Tests: `tests/front_emit_wave3_test.smith`, `tests/front_emit_option_test.smith`, `tests/front_emit_for_test.smith`.

**Arithmetic** (`emit_arith.smith`): literals, names, locals, `+ - * / %`, shifts, comparisons, assignment.
- Signed `+ - *` and negation use `llvm.*.with.overflow`; division and remainder check zero and `MIN / -1`; a shift checks its width; unsigned wraps.
- Each failing check goes to its own `fail` block that calls a `.smith` report function, then to the function's one `trap` block (K6, #1389, #1542).
- The reports are in `lib/std/contract.smith` (`fail_cast`, `fail_index`, `fail_overflow`, `fail_negate`, `fail_divide`, `fail_shift`): `index 7 is outside 0 to 3`, `7 / 0 divides by zero at f.smith:4:14`.
- `at` is `<file>:<line>:<column>` of the node's `Span.start`, from a line table made whenever `Options.source` is not empty. The branch to `fail` carries `!prof` weights (1 against 2000, #1550).
- `emit_jit` defines the report symbols in the JIT (`define_checks`); an object links `std::contract`.
- Built-in type names (#1576): smith's `i8 .. usize bool char` and today's capitalized names give the same `Ty`; `isize` and `usize` are pointer-wide on the target (64 bits with no data layout).
- `Char` is an unsigned `i8` in the IR with the layout of `U8` (K4, #1345); a character literal is that constant whatever the hint says.

**Control flow** (`emit_control.smith`, #1131): `if`/`else`, `while`, `do while`, `for`, `break`, `continue` (through `Emitter.loops`), `&&` and `||` (short circuit with a phi), `!`, `?:`.
- A condition is a `Bool`: an integer condition is an Error, "a condition is a Bool; write `x != 0`". A function whose end is reached without `return` branches to the `trap` block.
- A number where a Bool is wanted (`expected Bool, found Usize`) has a fix: ` != 0` after the expression, `(a + b) != 0` for one that is not a name, member, call, index or literal (`nonzero_fix` in `types_decl`, #2669).
- A call inside a generic is recorded once per instance of the function that holds it (`InstanceUse.outer`, `types::instance_called_in`, #2669); the emitter asks with the instance it is emitting.
- `@align(N)` (D18, #2669): one argument, a compile-time power of two, otherwise "the alignment must be a power of two known at compile time"; at most once on a declaration (`check_align` in `types_attr`). Test: `tests/front_attr_test.smith`.
- `defer body` (#1583) waits on `Emitter.defers` with its scope depth and runs on every way out: the end of its block (newest first, skipped when the end is unreachable), `return` (after its value is computed, before `ret`), and `break`/`continue` (the defers deeper than the loop's `scope_depth`, then the jump); a deferred body is emitted once per way out.
- `switch`, `goto` and labels are `not emitted yet`.
- `for x in xs` (`emit_iter`) lowers to the plain indexed loop with no stream object: blocks `forcond`, `forbody`, `forstep`, `endfor` and a hidden counter in the entry block.
- `range(a, b, step)` adds through `llvm.*add.with.overflow` and ends the loop on overflow; a zero, negative or run-time step is `not emitted yet` (lead's decision, 2026-11-02).

**Memory** (`emit_memory.smith`, #1133): pointer, array (`T[N]`, N a literal) and record types (`Decl.record` becomes a named struct `<module path>::<name>`); a union, bit-field or unknown record is an Error.
- Every lvalue is a place (address plus stored type): `&x`, `*p`, `a[i]`, `s.f`, `p->f`; a read is the place plus a load; a base that is no lvalue is spilled.
- An array's index is checked against its count (a constant index in range needs no check); a pointer's is not.
- Array literals (#1624): `[a, b, c]` is an array value, its items converted to the element type; where a slice is expected it is stored in a fresh entry-block slot of the function and the value is `{ slot, count }`, so a literal evaluated again in a loop overwrites the same slot. `[]` is `{ null, 0 }` or `[0]T`, and an error with no type.
- `(Point){.x = 1}` and `{0, 0}` fill a zeroed temporary; `{}` of any other type (a `Result`, an option, a tuple, a slice) is that type's zero, and `{.circle = c}` of a payload enumeration is the variant `.circle(c)` (`emit_memory::compound`, `emit_match::variant_of`, #3036: the C-like forms the fixer keeps until the switch-over). `countof` of an operand whose type the emitter reads as a slice or a block reads the count at run time even when the checker kept no type for it (a field of a name bound by `.ok(ok) := x else:`); `null` takes the expected pointer type, and is the zero of a `fn` value or function pointer it is given to (`fix.set_loader(nullptr)`); a function of another module named as a value (`h.f = ops.twice`) is its address, as a local function's name is (`call::module_function_value`); a global whose value is `mem.zeroed(T)` is the zero constant of its type (`builtin::is_zeroed`); `Lambda(bool (i32))` and `Fn(...)` as a type are the `fn` value of their function type, as the checker types them (#3036); a value argument of `Option`, `Result` or `Checked` that is a chain of names (`Result(emit.Module, emit.Error)`) is the type it names, as in the checker's `typed_arguments`; a field left out of a construction whose default is `T()` of the field's own record (`span: Span = Span()` in another module) builds that record (`call::expected_record`); `sizeof`, `alignof` and `countof` read the target data, never the host.
- A file-scope variable is a global with a constant initializer, read and assigned by its bare name (`memory::is_global_name`). `emit::module` calls `memory::release`. A global of record type may be built by a construction (`const cfg: C = C(count = 3)`, #2205): positional and named arguments must be scalar constants, and a field left out takes its default (`memory::construction_constant`; test: `tests/front/e2e/global_struct_const.smith`).
- Checked casts (K2, #1329): `Options.checked` is the checker's `types::Checked` (null: no cast is checked). `cast` asks `types::cast_checked(...).needed`, then converts, converts back and compares.
- `p.x` through a pointer loads it and takes the pointee's field, as `->` does (#1580); `pp.x` on a pointer to a pointer is an Error. `p as usize` is `ptrtoint`, `n as *u8` is `inttoptr`, pointer-wide only.
- Affine values (`@affine`, #1986 of #1972, part of #1631): `front/affine.smith` (`affine::check_body`, called at the end of `types_decl::walk`, after the body is typed) reports a second use of a value of an `@affine` record (`Ty.affine`, set by `declare_nominal`): the same messages as `shim/affine.cpp` (`smith-affine: 'key' is used again; it was already used at line N`, with the note `'key' was first used here`). A path is a name or fields through values (`h.key`, never `p->key`); a use is an affine-typed path read, passed or returned, or `&key`; `x = v` makes `x` fresh; the branches of `if`, `if let`, `match`, `?:`, `&&` and `||` start from the state before them and join, except one that ends in `return`, `break`, `continue` or `goto`; a `defer` body counts where it is written. Loops are read once as straight-line code (`front/affine_loops.smith`, #1987): a use inside a loop of a value the loop did not declare is an error (`'key' is used in a loop, so it would be used once per iteration`) unless the loop assigns it; the plain loop is `for i in range(countof(keys)):` (or `range(0, countof(keys))`, and `range(3)` or `range(0, 3)` over every array of 3: the old rule's start of 0 and a bound that names the array or is its length, #3036) and `keys[i]` is the element's own place, as is `keys[0]` (a constant index); any other index is `an element of an array of affine values is used through a constant index or the counter of a plain loop`; `for k in keys:` declares `k` fresh each turn; an array or slice passed to a call is filled by it, so its elements are fresh. `switch` and lambdas are not read (payload-enum narrowing: #1988). A struct that holds an affine member is not affine itself. `types::Error` has a general `related` span with a `related_message`, printed by `front::compile` as a `note:` line, and a `$line` in the message becomes the line of `related` (`types::fail_related`).
- There are no zero values (#1810 of #1428): a declaration with no value is an Error (checker and emitter); `= undefined` makes the slot with no store, except that with `Options.fill_undefined` (`compile` sets it: objects are made at optimization 0) the slot is filled with the byte 0xAA (`declare_undefined`). The fix-it writes `let mut x: T = undefined` for `T x;` (`= 0` for a static or a file's number, which C zeroes). A read of an `undefined` local (`let mut x: T = undefined`) before any write is an error (`types_undefined::check_body`, #1854): the first later statement of the same block that reads it when none before it wrote it; a statement that both reads and writes it, a write by `&x`, `x[i] = e`, `x.f = e`, passing it to a call, and code the pass does not read (lambdas, `if` as a value) all allow it. At most 32 undefined locals of one block are followed.
- Lint checks of smith's own (`front/lint.smith`, #1976 of #1631), run by `types_decl::check_module` as checker errors with the message text of the clang-tidy checks they replace: `smith-unsafe` (a call of C's `setjmp`, `longjmp`, `sigsetjmp`, `siglongjmp` or `alloca`), `smith-mem` (C's `memcpy`, `memmove`, `memset`, `memcmp`, `malloc`, `calloc`, `realloc`, `free`) and `smith-bounded-loop` (`while true`, a constant `for` or `do ... while` outside `main`). A call is C's when written `c::name`, through a C header's alias or stem, or imported by `from c <header> import name`; `mem::free` and a module's own `free` are not. A function that calls `contract::trusted()` is skipped. `smith-module-library` (`import c <smith/arena.h>`, and a `c::name` that the header's `// smith-module:` and `// smith-names:` lines pair with a module's name, in expressions and in the types of parameters, results, fields and `let`s) reads headers through `lint::set_header_text(fn(header, angled) -> text)`; with none set the check is off; `front/compile.smith` sets it (`read_header_text`: a quoted header in the file's folder, then `include/` and `<library>/../include/`) in `diagnose` and `compile`. The opt-out is `# NOLINT` or `# NOLINT(smith-mem, smith-unsafe)` (`*` or no list: every check) on the finding's line, or `# NOLINTNEXTLINE(...)` on the line before; the checker holds no comments, so `lint::set_source(text)` gives it the file's text (empty: nothing is silenced), each finding is tagged with its check, and `check_module` drops the silenced ones. The driver (`compile::diagnose` and `compile::compile`) calls `lint::set_source` with the file's text, so `smith lint`, `smith check` and the language server apply the opt-out.
- `vec(T, N)` (#1630): `T` a number type, `N` an integer literal of 1 or more; `vec(f32, 4)(1, 2, 3, 4)` or a list `[1, 2, 3, 4]` where a vector is expected; element-wise `+ - * / %` and the comparisons (a `vec(bool, N)`) between two vectors of one type or a vector and a scalar of its element; `v[i]` and `v[i] = x` (a constant index out of range is an error, a run-time one is checked). Emitted as one `<N x T>`. Not yet: signed integer lanes' arithmetic (the overflow checks), integer division, bitwise operators and unary `-` on a vector, `v += w`, swizzles, writing a lane of a `vec(bool, N)`.
- `fn` values (#1620): a lambda is an internal function `<symbol>::lambda.<n>` taking its context first; a lambda written as a call argument captures locals by reference, one that captures nothing has a null context, `f(a, b)` on a `fn` local is an indirect call. Still not emitted: slices, unions, pointer arithmetic and comparison, a stored lambda with captures, a function named as a value.

**Calls** (`emit_call.smith`, #1132): `f(a, b)` names a function or a prototype (a `Decl.function` with no body) of the module; a path is joined by `::` and a prototype named with `::` is its own symbol. A method call `x.f(a)` (#1796 of #1793) is emitted as the call the checker recorded (`types::method_of`): `f(x, a)` or `f(&x, a)`; `f` of the type's module links as `lib::list::f`, as `m.f` does. A record of another module is emitted as in the modules paragraph above (#1935). Tests: `tests/front_emit_method_test.smith`.
- Arguments run left to right with the parameter as hint; count and types must match (an Error at the argument), after `state::convert`.
- `Void` is an LLVM `void`; a `Void` function's reachable end emits `ret void`, any other function's traps. A function may be variadic (`...`, extra arguments after C's default promotions): `extern`, or with a body (#2611), which reads its arguments with `mut arguments: __builtin_va_list = undefined`, `__builtin_va_start(arguments, last)`, `__builtin_vsnprintf(out, size, format, arguments)` and `__builtin_va_end(arguments)` (`llvm.va_start`/`llvm.va_end` on the list's address, the list a 32-byte `[4]u64` as the 64-bit ABIs pass it; test: `tests/front/e2e/variadic_definition.smith`, called from C by `tests/front_e2e_test.smith`). In smith's own syntax `extern fn name(a: T, ...) -> R` (#2076) has no body, `...` is allowed only there (elsewhere the error says to write `rest...`), its symbol is its own name (`@c_name` overrides), and the checker (`check_variadic_arguments` in `types_expr.smith`) rejects an argument past the fixed ones that C cannot receive (a `str` variable, a struct); tests: `tests/front/e2e/extern_variadic*.smith`.
- Named arguments (#1579): `name = value` fills the parameter of that name (the checker's `argument_slot`), evaluated in written order; unknown or doubled names are Errors.
- A call whose callee is a record builds it, `Point(x = 1, y = 2)`: a field left out takes its default, written as one more named argument (`insertvalue` per argument), and a parameter left out takes its default the same way; a positional, unknown or doubled field is an Error.

**Functions in smith's own syntax** (`emit.smith`, #1577): `pub` is external linkage; `@inline`, `@noinline`, `@cold` are `alwaysinline`, `noinline`, `cold`; `@c_name("x")` makes `x` the symbol, for a function, a prototype (also one of an imported module) and an `extern` global: how `std::autodiff`'s `__enzyme_autodiff` and `enzyme_out` are declared (#1975, tests: `tests/front_emit_autodiff_test.smith`). A global of an imported module (`autodiff.out`, `autodiff::out`) is read by `emit::imported_global`: declared external under its `@c_name` (else its key) when first read (test: `tests/front_join_test.smith`). A module function casts to a pointer (`square.cast(*mut void)`, a `lea` of its address, emitted by `emit_arith::function_address`) and `*f64`, `*void` are pointee types the emitter reads, so a generic `gradient` can call the header's variadic `probe.__enzyme_autodiff(f.cast(*mut void), dup, x, ...)` (test: `tests/front_join_test.smith`). Header extern globals are not read by cimport yet, so the markers are declared in the module with `@c_name`. Not yet: `lib/std/autodiff.smith` itself in the new syntax.
- A function named `main` has the symbol `main`. The last line of a body, an expression statement with a non-`Void` result, is returned as `return <expression>`.
- `let _ = f()` evaluates and drops the value; a local `const X = v` is an ordinary slot stored once. Tests: `tests/front_emit_fn_test.smith`.

**Debug info** (`emit_debug.smith`, B5, #1135): with `Options.debug_info`, a DIBuilder, a C11 compile unit (producer `smith`), a `DISubprogram` per function (name as the source writes it, the full path, `geometry.box.area`; linkage name the symbol, `geometry::box::area`; #1979), a `DILocalVariable` per parameter and local, and a `DILocation` on every instruction.
- `smith cc --front-end=new -g` sets `SMITH_FRONT_DEBUG=1` (`runtime/front_flag.c`), which `front::compile` reads into `Options.debug_info`; without `-g` an object has none. `smith dbg` then shows `area(w=3, h=4) at hello.smith:2:5` and the locals (#1979). A lambda or generator with `-g` is still `not emitted` (`emit_lambda`, `emit_stream`). `start_function` clears the builder's location so one function's entry branch never carries the previous function's scope.
- A name or literal keeps the location of the statement or operator around it; a continuation gets the location of the node that pushed it (`debug::then_location`).
- The line table is `Emitter.line_starts`; there is no file-level state, so two emits can run at once. `debug::release` runs on every exit. Test: `tests/front_emit_debug_test.smith`.

- A record imported with `from std.build import Build` is the imported module's record in the emitter too (`emit_memory::is_imported_record`, `imported_record`), as a type and in a construction, and a field whose default is `= undefined` is left unwritten by a construction rather than read as a name (`emit_call::fills`) (#3026: the `unknown type Build` of the build files).
